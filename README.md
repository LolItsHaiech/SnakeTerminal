A ZSH plugin that makes you type your commands only by playing snake!

## requirements
1. python 3
2. ZSH shell


## installation

1. clone this repository
```
git clone git@github.com:LolItsHaiech/SnakeTerminal.git
```

2. add this line to your ~/.zshrc

```
source /path/to/snake.zsh
```

## configurations
by editing the config.json you can change the game variables

### spawn modes
0. completely random
1. ordered in a table (default)
